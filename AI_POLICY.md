# AI policy

We support using AI, including large language models, as tools when
contributing to Z-Wave JS projects. You are responsible for every contribution
you submit. Maintainers are responsible for every contribution they merge and
release. We hold a high standard for all contributions to our projects.

Our maintainers dedicate their time and expertise to reviewing contributions.
Submitting AI-generated content that you have not personally reviewed and
understood wastes that time and will not be accepted.

## Autonomous agents

**We do not allow autonomous agents to contribute to our projects.** We will
close pull requests or issues that we believe were created autonomously. We may
also mark automated comments as spam. This includes contributions that bypass
the provided issue or pull request templates.

## Communication on issues, pull requests, and code reviews

You may use AI tools to help you write. However, do not allow tools to post
unreviewed content on your behalf. Keep responses to the minimum needed to
communicate your intent. We may hide comments that we believe are unreviewed AI
output.

If you open a pull request, you must be able to explain the proposed changes in
your own words. This includes the pull request description and responses to
questions. If you use AI to help generate the pull request summary, you must
review it for technical accuracy.

**Do not use AI to generate answers to questions from maintainers.** You must
understand and be able to explain your own work. You may use AI to improve
grammar or clarity, but the substance of your responses must be your own.

If you include context from an interaction with AI in a comment, format it as a
quote block using `>`, and disclose its source. Add your own commentary that
explains the relevance and implications. Do not share long excerpts.

## Non-native English speakers

We understand that AI can help people communicate in a language that is not
their native language. You may use AI to improve the grammar or clarity of text
you wrote yourself. If you use AI to translate a comment, make sure the
translation accurately reflects your intent. Including your original text in a
details block shows the effort behind your contribution, helps maintainers
verify the translation if needed, and keeps the conversation readable.

## Code and documentation contributions

AI can be a helpful tool for writing code and documentation. Z-Wave JS projects
are foundational open source software, so we require a human contributor who
understands any work produced with AI assistance.

You must review and understand every contribution before submitting it. You
must be able to explain every code and documentation change in a pull request
you submit. Pull requests that appear to contain unreviewed AI output will be
closed without review.

## Our use of AI

Some Z-Wave JS projects use AI tools to assist with code reviews, issue
triaging, reporting, and other project management tasks. These tools may leave
comments on pull requests or issues. Like other automated tooling, these
comments can be incorrect.

If an AI tool comments on your contribution, treat the comment like any other
review comment. If you believe it is incorrect, say so. A brief explanation is
enough. Maintainers always have the final say. Ask a maintainer if you are
unsure.

## Enforcement

Contributions that do not follow this policy will be closed. Repeated
violations may result in being blocked from contributing to Z-Wave JS projects.
If you believe your contribution was closed in error, contact a maintainer to
discuss it.
